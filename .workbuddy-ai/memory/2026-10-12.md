# 2026-10-12 — Cozy Pomodoro (kawaii Pomodoro tətbiqi)

## Nə edildi
İstifadəçi üçün `C:\Users\ASUS\Documents\Pomodoro` layihəsində **Cozy Pomodoro** adlı
tam frontend Pomodoro taymeri quruldu. Backend yoxdur — hər şey brauzerdə işləyir.

**Stack (istifadəçinin seçimi: "Seçim 2"):** React 19 + Vite + TypeScript + Tailwind CSS v4
+ @phosphor-icons/react. Layihə artıq Vite+React+TS skafoldu olduğu üçün üzərinə quruldu.

## Fayl strukturu
```
index.html               → şriftlər (Quicksand+Nunito), lang="az", data-mode="focus"
preview.html             → yalnız dev üçün maskot qalereyası (/preview.html)
vite.config.ts           → react() + tailwindcss() plugin
src/types.ts             → Mode, Task, DayStat, Settings, MODE_META
src/lib/storage.ts       → localStorage açarları (cozy-pomodoro:v1:*), todayKey, lastNDays, uid
src/lib/audio.ts         → CozyAudio sinfi (Web Audio API, sintez olunmuş lo-fi/yağış/zəng)
src/hooks/useLocalStorage.ts
src/hooks/usePomodoro.ts → drift-free geri sayım, rejim keçidləri, start/pause/reset/skip
src/components/          → Icon, Character, Confetti, DurationPicker, TaskPanel, StatsPanel, SoundPanel
src/styles/              → tailwind.css (preflight-siz), global.css (tokenlər), components.css
src/preview/main.tsx     → maskot qalereyası
```

## Əsas texniki qərarlar
1. **Səs faylı YOXDUR** — lo-fi akkordlar, yağış və zəng Web Audio API ilə real vaxtda
   sintez olunur. Nəticə: 0 KB media, tam offline işləyir, sonsuz loop problemi yoxdur.
2. **Xarakter əl ilə çəkilmiş SVG-dir** (Lottie əvəzinə) — 6 səhnə: typing/reading/tea/
   music/sleep/celebrate. `transform-box: fill-box` olmadan SVG-də CSS transform işləmir.
3. **Tailwind v4 preflight-siz qoşuldu** (`@layer theme,base,components,utilities` +
   yalnız `theme.css` və `utilities.css` import) ki, öz dizayn sistemi pozulmasın.
4. Rejim rəngləri `<html data-mode="focus|short|long">` + CSS `--accent*` dəyişənləri ilə.

## ⚠️ Tapılan tələlər (TƏKRAR ETMƏ)
- **Tailwind sinif toqquşması:** öz `.ring` sinfim Tailwind v4-ün hazır `ring` utility-si
  ilə toqquşdu → SVG-nin ətrafına görünməz 1px kvadrat box-shadow çəkdi. `.timer-ring`-ə
  dəyişdirdim. `.sr-only` da Tailwind-də var → `.visually-hidden` etdim.
  **Qayda: öz sinif adlarını verərkən Tailwind utility adlarını yoxla.**
- `src/app/` altındakı fayllardan `../components/...` kimi import lazımdır (`./` yox).
- SVG-də CSS animasiya üçün `transform-box: fill-box` mütləqdir.
